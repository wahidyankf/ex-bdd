# Plans Convention Modules

Read in order. Each module is a self-contained part of the rule the [Plans Convention](../plans.md) entrypoint indexes.

Modules 010 to 019 hold:

- **[010 Authorization and Execution Record](010-authorization-and-execution-record.md)**: the owner's request before a
  plan is written, and the execution record atop delivery
- **[011 Phase Boundaries and Delivery Choices](011-phase-boundaries-and-delivery-choices.md)**: the delivery-grammar
  choices an adopter fixes once, with their trade-offs
- **[012 Decision Records](012-decision-records.md)**: what each material decision records, including the trigger that
  reopens it
- **[013 File Impact](013-file-impact.md)**: the annotated tree of every planned path, and its action labels
- **[014 Dependency Graph and Recovery](014-dependency-graph-and-recovery.md)**: delivery ordering, what may run
  concurrently, and conditional recovery items
- **[015 Evidence Files](015-evidence-files.md)**: where a plan's evidence files live, what stays inline, and how
  captures are named
- **[016 Learning Triage](016-learning-triage.md)**: the gates a learning passes before promotion, the empty-log record,
  and anti-theater guardrails
- **[017 Learning Routing](017-learning-routing.md)**: why a code-changing learning leaves the plan, and the timing
  choices an adopter fixes
- **[018 Bug-Fix Plan](018-bug-fix-plan.md)**: the one-document plan for a single defect, its sections, and the rules it
  is exempt from
- **[019 Migration Numbers](019-migration-numbers.md)**: how a migration takes its number at use, why a number a plan
  names is a hint, and why an applied migration is never renumbered
