# Behaviour-Driven Development Modules

Modules of [Behaviour-Driven Development](../behaviour-driven-development.md), each holding one part of its rules.

## Directory Map

- [Discovery and Scenarios](001-discovery-and-scenarios.md) — Fixes how a story is examined from business, development,
  and testing perspectives before formulation, and the rules every Gherkin scenario follows.
- [Layers and Adapters](002-layers-and-adapters.md) — Defines the unit, integration, and end-to-end layers that bind the
  scenario corpus, how a test is classified, which test targets each project role carries, and the layer choices an
  adopter records.
- [Bindings and Exemptions](003-bindings-and-exemptions.md) — Requires strict resolution of every scenario step, forbids
  bindings that pass without exercising the subject, and limits an exemption to one scenario at one layer with a
  boundary reason and alternative proof.
- [Compliance and Reporting](004-compliance-and-reporting.md) — Separates static binding compliance from semantic
  review, fails the behaviour-coverage check on a missing binding or justification, places each scenario check in its
  gate, and requires a generated per-feature status report.
