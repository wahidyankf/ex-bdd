# Plan Anti Hallucination

The standards in this directory are indexed below.

## Directory Map

- [Grounding and Citation](001-grounding-and-citation.md) — Requires internal references in a plan to be checked against
  the current revision and external facts to carry a plain citation, forbids inline confidence labels, and fixes the
  order of refusal when a claim cannot be verified.
- [Absence and Completeness](002-absence-and-completeness.md) — Sets the evidence that claims of absence and
  completeness need: an error-checked search with a positive control, a diff against ground truth from its owning
  authority, and a concept sweep no single pattern satisfies.
