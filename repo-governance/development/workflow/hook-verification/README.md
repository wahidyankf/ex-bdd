Modules of [Hook Verification](../hook-verification.md), each holding one part of its rules.

## Directory Map

- [Capacity-Held Hook](001-capacity-held-hook.md) — Allows one authorized push of a task-owned branch to skip a pre-push

  head; plus the standing worktree-to-PR pre-authorization for task-owned branches with passing manual screens.
